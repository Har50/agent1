The Go gateway sits in front of the Fastify API:

- Redis (or in-memory) **sliding-window** rate limits
- Failure **circuit breaker** to protect paymaster float
- Path for private RPC routing / policy hooks

Run locally via `docker-compose.prod.yml` or the `gateway/` binary.
